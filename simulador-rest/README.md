# Simulador de comunicaciones REST

Responsable: **Luka**.

Espacio para la CLI que simula aceptación, rechazo, modificaciones, nómina y cancelación sobre una solicitud seleccionada. La excepción de interfaz gráfica de §4.2.2 aplica porque el equipo tiene tres integrantes.

Dependencias: contratos REST de Lauty, mensajes y estados del motor de Alejo y [contrato de integración](../docs/ACUERDO_DE_INTEGRACION.md). Solo debe ofrecer operaciones habilitadas; usar REST y no escribir tablas del motor. No se implementa la CLI en esta etapa.
